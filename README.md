# PrintForge

A 3D printing model library built with Next.js. Browse, search and filter
community-made models, view model details and download printable STL files.

## Features

- **Search** models by name, description or category with debounced URL updates
- **Category filters** and **sorting** (newest, oldest, most liked, A-Z)
- **Model detail pages** with related models, likes and share actions
- **STL downloads** generated by a Next.js route handler
- Responsive header, mobile navigation and footer
- Custom loading, error and 404 pages
- SEO metadata, sitemap and robots.txt

## Tech stack

- Next.js 16 (App Router, Turbopack)
- React 19
- TypeScript
- Tailwind CSS 4
- React Icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev     # start the development server
npm run build   # create a production build
npm run start   # run the production build
npm run lint    # run ESLint
```

## Project structure

```text
app/
  [3m3d-models/[0m          Model listing, search/filter and detail pages
  [3mabout/[0m              About and mission pages
  [3mapi/models/[id]/[0m    STL download route handler
  [3mcomponents/[0m         Shared UI (header, footer, cards, search, likes)
  [3mlib/[0m                Data access, search, sorting and category helpers
  [3mmodels.json[0m         Model data
categories.json          Category definitions
```

## Environment

Optionally set `NEXT_PUBLIC_SITE_URL` for canonical URLs, sitemap and robots:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```
